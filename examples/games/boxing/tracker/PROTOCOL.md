# 外部トラッカー プロトコル（boxing ⇄ 深度カメラ）

ブラウザ側（`tracker-source.js` の `WebSocketTrackerSource`）と、外部の姿勢トラッカー
（`tracker/tracker.py`）の間の取り決め。**WebSocket・1 メッセージ 1 フレーム・JSON**。

- 既定 URL: `ws://localhost:8770`
- ブラウザは起動時にここへ繋ぎ、**繋がればそれを使う / 繋がらなければ Web カメラへ自動フォールバック**する。
  接続が切れた場合も Web カメラへ切り替わる（UI に「深度トラッカー」/「Web カメラ」と表示）。

## 座標系

| 系 | 定義 |
|---|---|
| `px` | 画像の正規化 2D。`x` は 0=左端 / 1=右端、`y` は 0=上端 / 1=下端。**ミラーしない**（カメラが撮ったまま）。`visibility` は 0..1 |
| `xyz` | **右手系・メートル・カメラ座標**。`+X` 右、`+Y` 上、`−Z` がカメラの前方（＝人はマイナス z にいる。2m 先なら z ≈ −2.0） |

ミラー（鏡像）はブラウザ側で行う。トラッカーは**撮ったままの向き**で送ること。
`xyz` は省略可（Web カメラだけのトラッカーなら `px` のみ送る）。その場合ブラウザは
従来どおり 2D から奥行きを推定する。

## フレーム

```json
{
  "t": 1723459200123,
  "joints": {
    "nose":      { "px": { "x": 0.51, "y": 0.28, "visibility": 0.99 }, "xyz": { "x": 0.02, "y": 0.35, "z": -1.90 } },
    "shoulderL": { "px": { "x": 0.57, "y": 0.40, "visibility": 0.98 }, "xyz": { "x": 0.19, "y": 0.15, "z": -1.95 } },
    "shoulderR": { "px": { "x": 0.44, "y": 0.40, "visibility": 0.98 }, "xyz": { "x": -0.19, "y": 0.15, "z": -1.88 } },
    "elbowL":    { "px": { "x": 0.61, "y": 0.52, "visibility": 0.95 }, "xyz": { "x": 0.28, "y": -0.05, "z": -1.80 } },
    "elbowR":    { "px": { "x": 0.40, "y": 0.52, "visibility": 0.95 }, "xyz": { "x": -0.28, "y": -0.05, "z": -1.75 } },
    "wristL":    { "px": { "x": 0.58, "y": 0.44, "visibility": 0.93 }, "xyz": { "x": 0.16, "y": 0.10, "z": -1.62 } },
    "wristR":    { "px": { "x": 0.46, "y": 0.44, "visibility": 0.93 }, "xyz": { "x": -0.15, "y": 0.10, "z": -1.40 } },
    "hipL":      { "px": { "x": 0.55, "y": 0.66, "visibility": 0.90 }, "xyz": { "x": 0.12, "y": -0.28, "z": -1.95 } },
    "hipR":      { "px": { "x": 0.46, "y": 0.66, "visibility": 0.90 }, "xyz": { "x": -0.12, "y": -0.28, "z": -1.92 } }
  },
  "hands": [
    { "handedness": "Left", "landmarks": [{ "x": 0.58, "y": 0.44, "z": 0.0 }, "… 21 点 …"] }
  ]
}
```

- `t`: 送信側の時刻 [ms]。無ければ受信時刻を使う。
- `joints`: 上記 9 関節。取れないものは省略してよい（ブラウザ側は `visibility` 0 として扱う）。
- `hands`: 省略可。MediaPipe Hands と同じ 21 点（正規化 2D）。手の見かけサイズの信号に使う。

## 実装メモ

- ブラウザ側の受け口は `parseTrackerMessage()`（純関数）。壊れた行は捨てて接続は維持する。
- `xyz` が来ているフレームでは、ブラウザは**奥行き推定を使わず実測値**で腕と前後位置を作る
  （`frameToPlayerInput()`）。骨長は固定なので、実測の手首位置は IK の「目標」として使われる。
- 座標変換はブラウザ側の `xyzToRig()`：カメラ座標 → ゲーム座標は `diag(-1, +1, -1)`
  （プレイヤーはカメラと向かい合っているので左右反転、カメラに近づく＝敵に近づくので z も反転）。
